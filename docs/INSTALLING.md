# Installing

Buzón has no packages yet. Until the first release, build it from source:
[BUILDING.md](BUILDING.md).

The first releases will ship, from
[GitHub Releases](https://github.com/getnodalia/buzon/releases):

- a Flatpak bundle, for any distribution
- an AppImage
- `.deb` and `.rpm` packages
- a macOS DMG

None of them is signed by a paid certificate: on macOS, open the app the first
time with right-click → **Open**.
