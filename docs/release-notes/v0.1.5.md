Buzón se comporta mejor en Linux: el AppImage, los iconos y el icono del dock de GNOME.

*Buzón behaves better on Linux: the AppImage, icons and the GNOME dock icon.*

## Español

### Correcciones

- **AppImage en el dock de GNOME**: la ventana vuelve a agruparse bajo el lanzador correcto. El paquete guarda el identificador de aplicación, `StartupWMClass` e iconos alineados, sin lanzadores duplicados en el escritorio.
- **Permisos del AppImage**: el archivo empaquetado sale con bit de ejecución, para que instalarlo o integrarlo no exija un `chmod` a mano.
- **Iconos en Linux**: el tema de iconos de la aplicación ya no pelea con Nodalia; se evitan glifos rotos o ausentes al abrir el AppImage.
- Comprobación automática de la identidad de escritorio (`.desktop`, iconos y AppDir) en CI y al construir el AppImage.

## English

### Fixes

- **AppImage on the GNOME dock**: the window groups under the right launcher again. The package keeps the application id, `StartupWMClass` and icons in sync, without writing a second desktop launcher.
- **AppImage permissions**: the packaged file ships with the execute bit set, so install or desktop integration does not need a manual `chmod`.
- **Icons on Linux**: the app icon theme no longer fights Nodalia, which avoids missing glyphs when opening the AppImage.
- Automated check of the desktop identity (`.desktop`, icons and AppDir) in CI and when building the AppImage.
