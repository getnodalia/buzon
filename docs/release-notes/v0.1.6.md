Buzón repara de verdad el lanzador del AppImage en GNOME/Nodalix, encaja el rail de la barra lateral y pinta la interfaz con tokens Nodalia.

*Buzón really repairs the AppImage launcher on GNOME/Nodalix, fits the sidebar rail, and paints the UI with Nodalia tokens.*

## Español

### Correcciones

- **Lanzador AppImage en Nodalix / Gear Lever**: si el integrador escribió un `.desktop` con icono genérico (`mail-client`, arte de Nodalix-Icons) o un `StartupWMClass` incorrecto, Buzón lo repara en el mismo archivo al arrancar: instala los iconos hicolor en `~/.local/share/icons`, pone `Icon=` y `StartupWMClass` al id de la app, y no crea un segundo lanzador.
- **Barra lateral compacta**: el botón de añadir cuenta (y el de carpeta) ya no se corta en el rail de 80 px.
- **Tokens Nodalia**: la hoja de estilos usa `--ndl-*` en lugar de colores con nombre de Adwaita; los temas de Apariencia escriben esas variables, así que la interfaz sigue a NDL de forma coherente.

### Cómo actualizar desde 0.1.5

1. Sustituye el AppImage por el de 0.1.6 (o deja que la actualización in-app lo haga).
2. Ábrelo una vez: reescribe el lanzador integrado si hace falta.
3. Si tienes dos copias (`~/Applications` y `~/Aplicaciones`), integra solo una.
4. Comprueba en GNOME: un solo icono de Buzón en el dock/rejilla, ventana agrupada bajo él.

## English

### Fixes

- **AppImage launcher on Nodalix / Gear Lever**: when the integrator wrote a `.desktop` with a generic icon (`mail-client`, Nodalix-Icons art) or a wrong `StartupWMClass`, Buzón repairs that same file on startup: installs hicolor icons under `~/.local/share/icons`, sets `Icon=` and `StartupWMClass` to the app id, and does not add a second launcher.
- **Collapsed sidebar**: the add-account (and add-folder) control no longer clips in the 80 px rail.
- **Nodalia tokens**: the stylesheet uses `--ndl-*` instead of Adwaita named colors; Appearance themes write those variables so the UI stays coherent with NDL.

### Updating from 0.1.5

1. Replace the AppImage with 0.1.6 (or let in-app update do it).
2. Launch once so a bad integrator launcher is rewritten if needed.
3. If you have two copies (`~/Applications` and `~/Aplicaciones`), integrate only one.
4. On GNOME: one Buzón icon in the dock/grid, window grouped under it.
