Buzón 0.1.9 pone la versión en el nombre del AppImage para que Nodalia Launcher y la Tienda de Nodalix puedan instalarlo.

*Buzón 0.1.9 puts the version in the AppImage's file name so Nodalia Launcher and the Nodalix Store can install it.*

## Español

### Correcciones

- **Instalación desde Nodalia Launcher y la Tienda**: el AppImage se llamaba `Buzon-x86_64.AppImage`, sin versión, y el Launcher lo mostraba como «No disponible aquí». Ahora se llama `Buzon-0.1.9-x86_64.AppImage`, como el de Brújula, y se instala y se actualiza desde ambos.
- **Actualización en el sitio**: el AppImage sigue avisando de versiones nuevas a Gear Lever y AppImageUpdate, que ahora buscan `Buzon-*-x86_64.AppImage.zsync`.

### Cómo actualizar desde 0.1.8

Instala 0.1.9 desde el Launcher o la Tienda, o descarga el AppImage nuevo. Un AppImage de 0.1.8 no se actualiza solo a este, porque busca el nombre antiguo; hazlo una vez a mano.

## English

### Fixes

- **Installing from Nodalia Launcher and the Store**: the AppImage was called `Buzon-x86_64.AppImage`, with no version, and the Launcher listed it as "Not available here". It is now `Buzon-0.1.9-x86_64.AppImage`, like Brújula's, and installs and updates from both.
- **In-place updates**: the AppImage still tells Gear Lever and AppImageUpdate about new versions, which now look for `Buzon-*-x86_64.AppImage.zsync`.

### Updating from 0.1.8

Install 0.1.9 from the Launcher or the Store, or download the new AppImage. A 0.1.8 AppImage will not update itself to this one because it looks for the old name; do it once by hand.
